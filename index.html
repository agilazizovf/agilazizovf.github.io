Engineering

How the systems are shaped

Two paths I keep separate in my head, then three pieces of work where that showed up. Employer internals stay out.

01 · Desinftec

API and query performance

Problem
Authenticated APIs serving 500+ users were slower than they needed to be. The wait was in the request path, not in a missing feature.
Approach
I treated it as a data-access problem: which queries the handlers ran, what Hibernate was loading, and what the API could stop doing. Spring Security and JWT stayed the auth boundary.
Result
Average response time fell by about 30%. The service split around that work also made deploys smaller.

02 · Əminlər MMC

Performance on a live backend

Problem
A request is slow, or wrong, only after it is in production. The local path does not show it.
Approach
Follow the call from the API into the query. Remove work the request does not need. Confirm the change on the running system, not only in a unit of code that looked fine.
Result
This is current work. I am not publishing timings, table shapes, or business rules from inside the company.

03 · QRAVAN

A release path for four services

Problem
Four services meant four setup rituals. A release was a 10-minute procedure instead of a pipeline.
Approach
Docker Compose so a machine could start the set, and CI/CD so release was the same artifact rather than a second set of steps.
Result
Setup under an hour. Deployment around 2 minutes.
