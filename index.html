Systems, not just endpoints.

I'm a Backend Engineer based in Baku, Azerbaijan, currently building backend services at Otogo, a B2B platform connecting car service providers with businesses across the country. My focus is Java and the Spring ecosystem — Spring Boot, Spring Security, Hibernate/JPA — wired into clean REST APIs and dependable data models.

Alongside product work, I teach. I've spent the last two years mentoring junior developers and running backend training at Developia Engineering Academy, which keeps me honest about writing code other people can actually read and extend.

I care about the parts of backend work that don't show up in a demo: authentication that holds up, queries that stay fast under load, and services that deploy without drama.
